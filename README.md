# 这是一个公益项目

台灣總統賴清德的發言人譴責北京對《紐約時報》記者的驅逐行動，北京此舉是對賴清德去年12月通過影片連線參加《紐約時報》DealBook峰會一事的回應。
這位駐北京記者王月眉(Vivian Wang)於2月被驅逐。她並未參與DealBook峰會——一項通常邀請知名企業高管和政治人物的年度活動。中國官員數月來一直對王月眉的報導表示不滿，其報導經常涉及北京認為敏感的議題。
與此同時，中國試圖孤立台灣。北京將這個自治島嶼視為其領土，將任何與台灣領導人的接觸基本上等同為侵犯中國主權的行為。
台灣總統發言人郭雅惠週日在網上發表聲明表示，中國向媒體組織施壓，要求其不要與賴清德接觸，這是對新聞自由和記者安全的威脅。
